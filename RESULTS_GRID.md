# 全网格结果：学习残差 vs 训练无关质心（2026-08-16 起，持续更新）

> 由 `scratch_all_report.py` 生成，**改数据后重跑该脚本，不要手改表格**。
> 口径四条，都是这个项目付过学费的：
> 1. **只报配对 bootstrap 的 Δ**，不报跨运行的绝对分——`results.parse` 的相对行按各自
>    的满缓存分归一，而那个分逐运行漂移；绝对分也只在两臂样本集完全一致时才可比。
> 2. **共同基线** `__g8base`（全 11 panel × 8 ratio 那一次），所以各条线之间可比。
>    ratio 0.02 的基线是另跑的 `__b002`。
> 3. **完成判定看日志的 `Finished.`，不看条数** —— choice_eng 只有 18 条、qa_eng 20、
>    many_shot 54、summary 70、vt 90，按条数过滤会把这些**完整**的 panel 当成截断的。
> 4. ★ = 95% 配对 bootstrap 区间排除 0（`v2c` 是多种子，要**全部种子都显著**才给 ★）。
>    `—` = **该格没跑**，不是零。`°` = 该格**结构性退化**（见下）。`(n)` = 参与平均的种子数。

**`v2c` 与 `v2` 的关系**：`v2c` 不是复现 `v2` 的权重，而是同一配方下的**三个新种子**
（干净版删掉了 memoryless 下不参与前向的 8 个模块，构造时少消耗随机数 ⇒ 初始化不同）。
推理路径已验证与原版逐位等价：参数 / 打分器（60 次随机微分，0.000e+00）/ cache 的
`valid` 掩码 / 训练前向+RNG 流 / **训练反向梯度（max 差 5.8e-11）** / 真 7B bf16 端到端。

**`°` 是什么**：`ratio × clen < window(4096)` 时 `wrapper.py:286-292` 把 `chunk_ratio`
置 0，保留集变成"上下文最后 `ratio×clen` 个 token"——预算照给，但**选择规则从按门控分数
变成纯按最近**，分数完全不参与 ⇒ 任何改分数的方法恒为 no-op，Δ 必为 0。门槛
`clen > 4096/ratio`：0.2 只卡掉 gsm(86)/squad(203)，0.05 卡掉 repoqa(72k)，
**0.02 卡掉全部 11 个 panel**。所以 **0.02 那一列是阴性对照，不是结果**——它非零就说明
实现坏了。（注意"退化"指分数不再被使用，**不是精度崩掉**：一个占 20% 上下文的滑动窗口
